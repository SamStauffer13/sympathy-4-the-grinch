# Sympathy 4 the Grinch

Served at https://samstauffer.net/sympathy-4-the-grinch/ via GitHub Pages (personal account `SamStauffer13`).

## Deploy

Push to `main`; the Pages workflow publishes the repo root. Pages source must be set to **GitHub Actions**.
Never "Re-run" a failed deploy; use Run workflow.

## Pushing from this machine

The default GitHub login here is the work account, so pushes use the deploy-key alias `github-grinch`
(key `~/.ssh/grinch_deploy`, remote `git@github-grinch:SamStauffer13/sympathy-4-the-grinch.git`).
